# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
[Report a vulnerability](https://github.com/andylacroce/digitalfigments/security/advisories/new).

Don't open a public issue for a vulnerability. This is a personal site, so
responses are best-effort, but reports are welcome and read.

## Scope

The latest commit on `main` is the only supported version. Reports about
secrets, the Keystatic admin at `/keystatic`, security headers, or the CI and
deploy workflows are all in scope.
